Java was originally developed by James Gosling at Sun Microsystems (which has since been acquired by Oracle Engine Corporation) and released in 1995 as a core component of Sun Microsystems' Java platform.
The initial release was Java 1.0. It promised "Write Once, Run Anywhere" (WORA), providing no-cost run-times on popular platforms.
Java 5.0 introduced generics, enhanced for loops, autoboxing, and annotations.
Java 8 brought lambda expressions, the Streams API, and a new Date and Time API, marking a major functional programming shift.
Java 21 is a Long-Term Support (LTS) release featuring virtual threads, pattern matching for switch, and sequenced collections.
